
# 🎰 MEGARBAJEE BACKEND

A production-level backend system for wallet, gaming, and user management.

---

## 🚀 Features

- User Authentication (JWT)
- Wallet System (Deposit / Balance / Withdraw)
- Game Engine (RNG based win/lose)
- Transaction System
- Secure Middleware

---

## ⚙️ Tech Stack

- Node.js
- Express.js
- MongoDB
- JWT Authentication
- bcrypt
